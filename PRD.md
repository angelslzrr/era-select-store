# Producto: Landing Page "Era Select Store"

## Objetivo Principal
Crear una página web atractiva y amigable para presentar el catálogo de Era Select Store, un emprendimiento de venta de artículos para el hogar. La meta principal es que los visitantes vean los productos (que combinan diseños divertidos y soluciones prácticas) y se contacten fácilmente para comprar.

## Público Objetivo
Personas que buscan darle un toque cálido, útil y divertido a sus espacios del día a día.

## Funcionalidades Clave
1. **Hero Section (Inicio):** Mensaje de bienvenida claro con una imagen destacada que transmita calidez.
2. **Sección de Categorías:** Botones o tarjetas visuales para las 5 categorías del negocio: Hogar, Tecnología, Moda, Accesorios y Novedades.
3. **Galería de Productos:** Una muestra rápida de los productos estrella (ej. tazas con diseños amigables, organizadores).
4. **Call to Action (Llamado a la acción):** Botones enlazados directamente a WhatsApp para concretar las ventas de forma rápida.
