# Tecnologías a utilizar

## Frontend
*   **Framework:** React (usando Vite para mayor velocidad). Es ideal para crear componentes reutilizables (como las tarjetas de productos).
*   **Estilos:** Tailwind CSS. Perfecto para aplicar los colores personalizados del logo y el diseño minimalista de la referencia de forma rápida y responsiva.

## Integraciones y Despliegue
*   **Íconos:** Lucide React (para los íconos limpios de las categorías de Hogar, Moda, etc.).
*   **Hosting:** Firebase Hosting. Fácil de configurar, gratuito para empezar y súper seguro.
*   **Contacto:** API directa de "wa.me" (WhatsApp) para la gestión de pedidos.
